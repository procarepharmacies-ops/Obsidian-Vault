## 📋 Project Overview

**Obsidian-Vault** is a centralized knowledge management and operational documentation system for Procare Pharmacies. This repository serves as a comprehensive vault for organizational knowledge, AI-powered insights, and operational procedures.

### Key Features
- 🧠 **AI-Brain**: Machine learning and AI integration capabilities
- 📝 **Documentation**: Structured operational and technical documentation
- 🔧 **Scripts**: Automation and utility scripts for pharmacy operations
- 💼 **Skills**: Knowledge base and training materials
- 📊 **Kanban Boards**: Project tracking and task management


## 🚀 Quick Start

### Prerequisites
- PowerShell 5.0 or higher
- Obsidian (optional, for vault viewing)
- Git for version control

### Setup Instructions

1. **Clone the repository**
   ```bash
   git clone https://github.com/procarepharmacies-ops/Obsidian-Vault.git
   cd Obsidian-Vault
   ```

2. **Configure for local development**
   ```bash
   # Initialize local environment
   ./scripts/init-environment.ps1
   ```

3. **Open in Obsidian** (optional)
   - Open Obsidian
   - Select "Open folder as vault"
   - Navigate to the cloned repository
