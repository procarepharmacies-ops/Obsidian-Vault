## 🏛️ The Methodology: A.N.T.

We separate concerns into three distinct layers to ensure reliability, scalability, and transparency.

| Layer | Component | Responsibility |
| :--- | :--- | :--- |
| **A** | **Architecture** | `architecture/` - SOPs, technical maps, and "Source of Truth" documentation. |
| **N** | **Navigation** | The reasoning layer where the AI (Antigravity) routes data between SOPs and Tools. |
| **T** | **Tools** | `tools/` - Deterministic Python/PowerShell scripts that execute the actual work. |

---

## ⚡ The Execution Protocol: B.L.A.S.T.

Every task within this foundation follows a 5-phase lifecycle to ensure maximum quality and zero guesswork.

1. **Blueprint** 🏗️: Define the North Star, data schemas, and research findings.
2. **Link** 🔗: Verify API connections, environment variables, and handshake logic.
3. **Architect** ⚙️: Build the 3-layer system (SOPs → Navigation → Tools).
4. **Stylize** ✨: Refine the payload, UI, and professional delivery formatting.
5. **Trigger** 🛰️: Deploy, automate (Cron/Webhooks), and finalize documentation.

## 🚀 Starting a New Project

To spin up a new project from this base:

1. **Initialize Phase 0**: Run `scripts/01-install-plugins.ps1` to ensure the Obsidian environment is ready.
2. **Set the Law**: Update `AI-Brain/claude.md` with the specific project invariants.
3. **Define the Schema**: Add your Input/Output payloads to `AI-Brain/gemini.md`.
4. **Trigger the Loop**: Follow the B.L.A.S.T. protocol for each milestone.

## 🔑 Operational Invariants

- **Data-First**: No tool is built until its JSON schema is defined in `gemini.md`.
- **Self-Annealing**: On error → Analyze → Patch → Update Architecture SOP.
- **No Placeholders**: We generate production-ready assets, never Lorem Ipsum.
- **Source of Truth**: If it isn't in the vault, it doesn't exist.
